## 1. Derivation — the discipline from first principles

Quantitative finance is the study of **pricing, predicting, allocating, and
risk-managing claims on uncertain future cash flows**. Every topic in the field is
generated by eight primitives:

1. **Measurement** — prices, returns, and data whose integrity can be trusted
   (the field's empirical substrate).
2. **Time** — discounting: value today of cash later. One idea; equities and bonds
   are the same mathematics applied to different claim structures.
3. **Uncertainty** — stochastic models of how prices and states evolve.
4. **Equilibrium & efficiency** — why expected returns differ across assets (risk
   premia), what prices already know, and why any edge must be paid for
   (Grossman-Stiglitz: information has a cost, markets pay it).
5. **Arbitrage & replication** — pricing by no-arbitrage: derivatives, term
   structures, contingent claims.
6. **Inference & prediction** — extracting signal from noisy, non-stationary,
   heavily-mined data without fooling yourself; the discipline's statistical core.
7. **Aggregation** — combining claims into portfolios under estimation error,
   preferences, and constraints.
8. **Frictions & implementation** — costs, liquidity, market structure, execution,
   operations, governance: where paper returns go to die.

Every module, package, and lesson in this project maps to exactly one primitive.
Anything that maps to none is out; any primitive with no artifacts is a gap.

## 3. The three artifacts (what this project *is*)

Chosen by one criterion — **verifiability by a skeptical outsider**:

1. **An executable curriculum** covering all 18 areas — every lesson's code runs in
   CI against the library; claims cannot rot (a reader can *check*, not trust).
2. **A reference implementation**, deep where §4's neutral criteria permit genuine
   verification, integrating mature libraries elsewhere (rebuilding QuantLib badly
   proves nothing; teaching through it proves understanding).
3. **A live paper track record** — the same code path research→production, with
   inference corrections applied and the trials count disclosed.

## 4. Depth allocation — four neutral criteria, no inheritance

Each field area earns `[deep]` (built from first principles), `[integration]`
(taught by driving a mature library), or `[survey]` (concept + references), by
scoring four criteria — none of which reference prior work:

- **V — Verifiability:** does *free* data allow reproducing externally checkable
  numbers? (filings figures, Treasury curves, published factor premia)
- **T — Teachability:** does first-principles implementation create real
  understanding (vs re-plumbing)?
- **D — Distinguishing power:** does mastery here separate practitioners from
  tourists? (inference discipline: yes; CSV parsing: no)
- **S — Solo-reachable correctness:** can one person build it *right*, tested?

|---|---|

## 5. Architecture & principles

Packages mirror the primitives (structure grows only as areas land — no stubs):

```
quantropy/
  core/        # 1,3: returns, TVM/discounting, stats, simulation, numerics
  data/        # 2: PIT store, immutable snapshots, universes, providers (EDGAR, stooq, FRED/Treasury)
  markets/     # 5,6: macro context data, efficiency evidence utilities
  pricing/     # 8,9,10: valuation (equity claims), curves (fixed income), options (BSM/Greeks/trees)
  research/    # 11: signals, feature contract, signal lab, inference stack, registry/ledger
  portfolio/   # 12: covariance, construction, sizing
  backtest/    # 14: event-driven engine, costs, venue Protocol, SimulatedVenue
  risk/        # 15: VaR/ES + backtests, factor risk model, stress
  live/        # 16: IBKR venue, limits, reconciliation
  evaluation/  # 17: metrics, attribution, tearsheets
curriculum/    # the executable book — 18 areas, one home each
legacy/        # archived prior work; never imported (docs/PROVENANCE.md)
```

Principles (unchanged where externally justified — they are methodology, not
inheritance): tiered reference-value testing (analog of model validation, SR 11-7);
no look-ahead in engine *and* features; PIT/as-reported data; seeded, snapshot-pinned
reproducibility; one code path to live with modelled divergences; integrate-don't-
reinvent; honest labels (`[deep]/[integration]/[survey]`, `[backtest]/[paper]`);
secrets via environment; abstractions earned, not speculated.

## 7. Provenance audit — kept vs dropped (the anti-bias ledger)

Every element of prior versions was re-derived or removed:

| Element | Verdict |
|---|---|
| PIT/bitemporal store, immutable snapshots, survivorship universes | **Kept — canonical** (industry-standard point-in-time practice; required by area 2). |
| EDGAR ingestion | **Kept — canonical** (the free primary source for area 8; natively bitemporal). |
| Inference stack (deflated Sharpe, PBO, purged CV, trials ledger) | **Kept — canonical** (published discipline: Bailey–López de Prado, Harvey; area 11). |
| One-code-path sim/live venue | **Kept — canonical** (area 16 production practice). |
| Valuation "archetypes" (SOTP/serial-acquirer as organizing frame) | **Dropped — idiosyncratic**; replaced by the canonical model set. Reverse-DCF survives *as* market-implied expectations (Rappaport–Mauboussin — canonical). |
| Futures-first systematic framing (Panama roll, Carver sizing as defaults) | **Demoted** — TSMOM is one signal family among several in area 11; futures plumbing arrives when futures do. |
| "Rates/credit not retail-feasible" | **Reversed** — sovereign curves are free data; fixed income is a deep track (M4). |
| Retirement/TVM emphasis | **Reframed** — TVM stays as area-1 foundations (canonical), not as a product direction. |

**Convergence rule:** this map is complete against C/F/G/P by construction. From
here, changes require showing a cell one of the four authorities demands that the
map lacks — critiques attack artifacts, not the map.
