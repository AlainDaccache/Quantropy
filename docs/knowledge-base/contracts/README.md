## Ownership and status

The reference gives a learner path. These contracts own the method-family definitions. Legacy chapters remain requirements/discovery material. Until each exact variant has its own contract and claim evidence, the catalog must not be interpreted as 306 fully specified methods.

The [research work ledger](../RESEARCH-WORK-LEDGER.md) records incomplete detailed variants, source access and independent-review gates. The register's prerequisite links are checked for cycles. Reuse shared units and data definitions; do not repeat formulas in product requirements.
