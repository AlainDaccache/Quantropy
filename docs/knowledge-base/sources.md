# Source register and evidence boundaries

Research edition: 2026-10-05. Links identify primary authors, exchanges, regulators, broker/project documentation and original investor materials wherever possible. A source anchor supports the topic, not every design choice in a chapter. Architecture, acceptance criteria and build priorities are proposals synthesized for Quantropy. Source access depth is recorded below; an abstract is not represented as full-paper verification. No full proprietary articles or textbooks are reproduced.

Current documentation and legal/tax/data-provider policies can change. Pin the actual source/version and reverify before implementation or use. This bibliography is a starting corpus, not a claim that all underlying literature has been reviewed.
