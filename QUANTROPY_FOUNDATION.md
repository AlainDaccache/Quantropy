# Quantropy platform foundation

Quantropy is proposed as a financial knowledge, modeling, investment research and decision platform, with a full-stack application and a reusable financial library. It includes advanced portfolio/trading workflows and accessible educational calculators. Existing code on the repository's default branch is retained; this research branch does not certify or replace it.

The optimal sequence is broad domain research, detailed method/data specifications, independent financial validation, complete user workflows, integration/architecture proof, and gated runtime expansion. Research and foundational prototypes can proceed together; broad topic labels cannot establish detailed completeness.

All inventory entries remain candidates/specifications until exact source review, applicability, data contracts and independent examples are completed. No claim is made that every book or curriculum learning outcome has been reviewed, that any alpha is profitable, or that the app is implemented/live ready. Analysis, simulation and execution are separate maturity levels. Generic policy examples do not describe or authorize any particular user's account.

This branch is based on this GitHub repository's existing default-branch history. Only foundation documentation is added; unrelated local repository history, laptop audit files, private datasets and account records are excluded.
